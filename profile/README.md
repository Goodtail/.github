### 🚢 Porter

A native macOS process &amp; port manager. Monitor and safely control your dev servers —
on your Mac **and over SSH** — from a single window. The
`lsof -i :3000` → `grep` → `kill -9` loop becomes a couple of clicks, and remote
machines get the exact same UX as localhost.

```bash
brew install --cask goodtail/tap/porter
```

[**Repository →**](https://github.com/goodtail/porter) &nbsp;·&nbsp; macOS 14+ &nbsp;·&nbsp; Swift 6 &nbsp;·&nbsp; MIT &nbsp;·&nbsp; v0.1.0
