## 00 · Porter

**로컬 Mac과 SSH 서버의 포트·프로세스를 한 창에서 관리하는 macOS 네이티브 앱입니다.**

열린 포트를 찾기 위해 `lsof`, `ps`, `grep`을 오가고 PID를 다시 확인하던 흐름을
하나로 묶었습니다. 프로세스와 실행 명령을 확인한 뒤 안전하게 종료하거나 재시작할
수 있고, `~/.ssh/config`에 등록된 원격 서버도 로컬과 같은 방식으로 다룹니다.

```bash
brew install --cask goodtail/tap/porter
```
